⚠ PROTOTYPE — No RUL Model Connected
This section is a prototype interface for future Remaining Useful Life (RUL) predictions.

No trained RUL model exists in this project. The anomaly score and health state displayed elsewhere are not equivalent to RUL. A genuine RUL prediction requires a dedicated regression model trained on run-to-failure data with appropriate uncertainty quantification.

When Phase 2B connects the Phase 1 ML pipeline, this panel will display:
• Estimated remaining flight hours
• Confidence interval
• Degradation curve projection
• Scheduled maintenance recommendations
